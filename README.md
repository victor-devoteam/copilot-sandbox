# Copilot Sandbox

Un mini gestionnaire de tâches en HTML, CSS et JavaScript pour tester des idées et coder avec Copilot. Pas de framework, de serveur ni de dépendance à installer.

## Lancer l'application

Ouvre `index.html` dans ton navigateur. Les tâches sont enregistrées dans le stockage local du navigateur.

## Fonctionnalités

- Ajouter une tâche
- La marquer comme terminée ou à faire
- Filtrer les tâches (tout, à faire, terminées)
- Supprimer une tâche
- Retrouver la liste après rechargement de la page

## Idées d'exercices pour Copilot

Essaie de demander à Copilot de :

1. Ajouter un bouton pour supprimer toutes les tâches terminées.
2. Permettre de modifier une tâche déjà créée.
3. Ajouter une date limite et signaler les tâches en retard.
4. Ajouter un compteur de progression avec une barre visuelle.
5. Écrire des tests pour les filtres et la sauvegarde.
6. Ajouter un thème sombre avec un bouton de bascule.

Fais une demande à la fois, vérifie les changements dans le navigateur, puis demande à Copilot d'expliquer le code ou de proposer des cas limites.
